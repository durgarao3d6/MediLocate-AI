How the shopkeeper pilot works

01

Start a shop profile

Enter a pharmacy name and begin testing locally, without account registration.

02

Import rack information

Upload an Excel file or a rack photo. OCR suggests visible text; you assign the rack and shelf.

03

Confirm and save

Review medicine names, strengths and locations. Save approved entries on this browser.

04

Scan a test prescription

Use a printed synthetic prescription image or type medicine names. Review extracted text.

05

Find the rack

See exact matches and their rack/shelf locations. Unmatched entries remain flagged.

06

Test offline

Previously saved catalog data remains in the browser. OCR model downloads may require connectivity.

Built for a focused, safe pilot

This is an early prototype, not a dispensing or clinical decision system. Photo OCR may misread medicine names. Never use it to automatically substitute drugs, and do not upload real patient prescriptions or sensitive pharmacy data. Data is stored locally in your browser using IndexedDB—not native Android SQLite yet.
