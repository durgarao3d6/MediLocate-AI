Frequently asked questions

Good to know before you begin

Do I need to install an Android app?

No. The pilot is a browser-based web app. Native Android packaging and SQLite testing are still future work.

Can I use the pilot without registration?

Yes. Enter a shop name to create a local profile. This is not a secure user account; no password or cloud account is created.

Can I upload Excel files?

Yes, .xlsx files with columns for medicine name, strength, form, rack and shelf. You must review and confirm entries before saving.

Does AI automatically understand everything on a rack photograph?

No. OCR proposes visible text and can make mistakes. A shopkeeper must verify medicine identity, strength, formulation and location. A photo does not prove stock availability.

Can it read handwritten prescriptions?

Handwriting and multilingual prescription recognition are not validated. The current prototype uses experimental English OCR and supports manually entered test text.

Where is my catalog saved?

In local browser storage (IndexedDB). It is not native SQLite, does not synchronize between devices, and can be lost if browser data is cleared.

Is this ready for real patients or dispensing?

No. This is a synthetic-data usability pilot. Authentication, privacy controls, clinical verification and device testing are still required before real-world deployment.

Important pilot safety note: Use only synthetic medicine and prescription data. Never upload real patient information. Always verify medicine name, strength and formulation with a qualified pharmacist. MediLocate AI does not make dispensing decisions or recommend substitutions.
